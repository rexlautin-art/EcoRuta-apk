# EcoRuta

Carpetas:

- `celular/`  App del celular (APK) + el **puente** (servidor del PC: `servidor/`, `iniciar_ecoruta_internet.bat`).
- `panel/`    App del computador (EcoRuta Admin, instalador `.exe`).
- `.github/workflows/`  Las "recetas" que compilan todo automaticamente en GitHub (pestana **Actions**).

## Obtener los archivos listos
1. Entra a la pestana **Releases** (columna derecha) y abre la ultima version.
2. En **Assets** estan: `EcoRuta.apk` (celular), `EcoRuta-Setup-x.y.z.exe` (PC) y `EcoRuta-puente.zip` (servidor del PC).

## Crear una version nueva
**Releases > Draft a new release > Choose a tag > escribe `v1.0.1` > Publish release.** Espera 10 minutos y recarga.

Guia completa paso a paso: ver el PDF "Guia EcoRuta con GitHub".
